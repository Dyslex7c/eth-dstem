## 1. Artifacts and loading

## 2. P/Invoke boundary contract (proposed `crates/dstem/src/ffi.rs`, `#[no_mangle] pub extern "C"`)
Blittable args only: `TxHash = [u8; 32]`, `PeerId = [u8; 64]` [S14 `types.rs:3-4`] cross as caller-owned `byte*` of exactly 32/64 bytes; the handle is an opaque `Box<StemService>` pointer. Return codes: `1` = stemmed (out-buffer written), `0` = fluff / nothing, `<0` = error (`-1` null arg, `-2` bad `stem_prob`, mapping `handle_inbound_stem`'s `Err` [S14 `service.rs:22`]). Count-returning calls write at most `cap` entries and return the total so the caller can re-call with a larger buffer. `StemService` is `Send + Sync` (parking_lot) [S14], so calls may come from any .NET thread; the handle must be freed exactly once. Exports MUST NOT unwind: wrap bodies in `std::panic::catch_unwind` or build with `panic = "abort"` [S17 `link.unwinding`].

## 4. Tx-pool hooks (`Nethermind.TxPool`) — interception points, all proposed
- **Local origin:** `TxPool.SubmitTx(Transaction tx, TxHandlingOptions handlingOptions)` (`TxPool.cs:1684,1717`) currently reaches `_broadcaster.Broadcast(tx, isPersistentBroadcast)` at `:2019` → `TxBroadcaster.NotifyPeersAboutLocalTx` sends the **full tx to every peer** (`TxBroadcaster.cs:109-133,445-455`). Insert before `:2019`: `if (!tx.CarriesBlobs && dstem_handle_inbound_stem(h, tx.Hash.Bytes, p, out next) == 1) { _stemHeld.Add(tx.Hash); SendStem(next, tx); } else Broadcast(...)`. Blob txs are never stemmed (`eth68s-stem-spec.md:15`).
- **Inbound stem:** `Eth68sProtocolHandler` decodes `0x0b`, then fetches the body with eth `GetPooledTransactionsMessage` — the existing path is `Eth68ProtocolHandler.Handle(NewPooledTransactionHashesMessage68)` → `RequestPooledTransactions` (`Eth68ProtocolHandler.cs:119,141,146-150`), which is `protected`; expose an `internal` entry on the eth handler obtained via `Session.TryGetProtocolHandler(Protocol.Eth, …)` (`ISession.cs:49`). The fetched body then goes through `_txPool.SubmitTx(tx, TxHandlingOptions.None)` (gossip path as at `Eth62ProtocolHandler.cs:460`) with a new `TxHandlingOptions.StemHeld` flag so `:2019` runs the coin instead of broadcasting.
- **Suppression while held:** `TxBroadcaster` must skip `_stemHeld` hashes in `Broadcast`, the 1000 ms rebroadcast timer and `NotifyPeersAboutLocalTx`; `GetPooledTransactions` serving must skip them for all peers except the chosen stem peer (exact serving line: `unknown`, TODO(verify)). **Fluff:** a timer calling `dstem_collect_expired(h, dstem_now_ms(h))`, plus `ITxPool.RemovePeer(PublicKey)` (`ITxPool.cs:70`) → `dstem_peer_drop`, each clearing `_stemHeld` and calling `_broadcaster.Broadcast(tx, true)`. Phase is one-way per `eth68s-stem-spec.md:48-52`; `dstem` itself enforces no phase guard (`service.rs:20-32`).
